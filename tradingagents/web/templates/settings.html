OpenRouter gives both model tiers access to multiple providers through one key. Choose the analyst and manager model IDs each time you start an analysis.

Connect OpenRouter

  1. Create a key in your OpenRouter account.
  2. On the server, add it to your private .env file:
    OPENROUTER_API_KEY=your-key-here
  3. Restart the website, then start an analysis.

The key stays on the server. “Key configured” checks that a value exists; a completed analysis confirms provider access. The key is never sent to your browser.
